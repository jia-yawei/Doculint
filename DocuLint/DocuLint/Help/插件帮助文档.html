安装与启用

适用环境

  • Microsoft Word 桌面版。
  • .NET Framework 4.7.2。
  • Microsoft Visual Studio 2010 Tools for Office Runtime。
  • 单机内网电脑可以离线安装，但安装包中需要包含上述运行环境或提前安装。

安装步骤

  1. 关闭所有 Word 窗口。
  2. 运行发布包中的 setup.exe。
  3. 如果提示安装 .NET Framework 或 VSTO Runtime，按提示安装。
  4. 如果提示证书或发布者不受信任，确认来源是内部发布包后继续安装。
  5. 重新打开 Word，功能区中应出现 搞快点 选项卡。

重新安装或升级

  1. 关闭 Word。
  2. 在“控制面板 - 程序和功能”中卸载旧版本，或直接运行新版本安装包覆盖安装。
  3. 重新打开 Word 后，在插件最右侧 关于 - 版本号 中确认版本。
如果 Word 启动后没有出现插件，先到 文件 - 选项 - 加载项 查看是否被禁用。若在“禁用的项目”中看到本插件，需要重新启用后重启 Word。

推荐写作流程

  1. 打开或切换文档：用“文档管理 - 切换窗口”在已打开的 Word 文档之间切换。
  2. 确定标题层级：使用“样式管理”的“当前样式”和“大纲级别”设置标题和正文。
  3. 建立样式绑定：需要统一章节号时，打开“样式绑定”，把大纲级别、样式、多级列表规则关联起来。
  4. 更新章节号：在“快速工具 - 更新 - 更新所选章节号”中刷新光标所在段落或选区内标题编号。
  5. 插入题注和引用：图片、表格旁插入题注，再用引用题注生成动态交叉引用。
  6. 整理表格和图片：跨页表格拆分、快速表格样式、图片单倍行距等统一处理。
  7. 检查问题：使用文档检查找章节标题为空、题注连续性、多级列表连续性、样式一致性和未更新域。
  8. 需求提取与追踪：软件文档中先提取需求标识，再补充需求名称，最后在追踪控制台建立映射并导出追踪表。
  9. 更新目录和域：最终交付前更新目录、总页码、题注和交叉引用。
长文档建议先保存一份副本，再执行批量替换、清理手工编号、清理空白页等不可逆程度较高的操作。Word 的撤销通常可用，但跨文档批处理不建议完全依赖撤销。

批量处理

批量替换

用于按规则在当前文档、多个文件或文件夹内执行查找替换。

典型场景

  • 项目名称、单位名称、版本号批量替换。
  • 模板文档中固定占位文字批量改成当前项目内容。
  • 多个交付文档需要统一术语。

使用步骤

  1. 点击 批量替换。
  2. 选择需要处理的文件或文件夹。
  3. 录入查找内容和替换内容。
  4. 点击 开始替换。

格式刷

调用 Word 原生格式刷。先选中具有目标格式的文字或段落，点击 格式刷，再刷到目标位置。

样式管理

当前样式

下拉框显示当前文档可用样式，选择后应用到当前光标所在段落或选区。

大纲级别

用于设置当前段落的大纲级别，支持 1 级到 9 级以及正文。Word 导航窗格、目录和章节号更新主要依赖大纲级别识别标题。

创建自定义样式

用于创建“通用1级标题”到“通用9级标题”和“正文”等样式。配置界面中只有勾选“是否创建”的样式才会写入当前文档。

  • 可设置大纲级别、字体、字号、对齐方式、加粗和行距。
  • 默认不强制全部创建，避免污染文档样式库。
  • 适合新建文档或模板样式混乱时建立一套干净样式。

样式绑定

用于配置“大纲级别、样式、多级列表”之间的关系。绑定顺序是：样式绑定到大纲级别，多级列表绑定到样式。

  1. 点击 样式绑定。
  2. 为每个大纲级别选择对应样式。
  3. 选择多级列表样式，例如 1、1.1、1.1.1 或带点格式。
  4. 设置编号和标题之间的间隔。
  5. 确认后再执行 更新所选章节号。

预期结果：相同大纲级别使用同一套样式和编号规则，章节号按文档顺序生成。

题注与引用

插入图片题注

在当前光标处插入 图X，编号使用 Word 字段，便于后续刷新和交叉引用。题注段落会设置为题注样式并居中，字体为黑体小四。

插入表格题注

在当前光标处插入 表X，编号同样使用 Word 字段。适合表格上方题注。

引用题注

  • 直接点击按钮：默认引用下一个题注。
  • 下拉 - 引用下一个题注：从当前位置向后查找题注并插入动态引用。
  • 下拉 - 引用上一个题注：从当前位置向前查找题注并插入动态引用。
  • 下拉 - 引用自定义题注：弹出列表，选择具体图注或表注后插入引用。

预期结果：题注编号变化后，点击“更新 - 更新题注”即可同步题注和引用结果。

窗格显示

窗格用途
书签窗格显示当前文档书签，单击项目可定位到书签位置。
图注窗格显示图片题注，便于检查图注缺失、跳号或位置异常。
表注窗格显示表格题注，便于检查表注缺失、跳号或续表异常。
标识窗格显示当前文档中识别到的 SRS、SDS、SDD 等标识。
文档检查结果窗格显示检查问题列表，单击可跳转到对应位置。

文档检查

检查项

  • 章节标题为空：检查大纲级别 1-9 的章节标题是否没有文字或只有编号。
  • 题注连续性：检查图注、表注编号是否连续。
  • 多级列表连续性：检查章节号是否符合大纲层级顺序。
  • 样式一致性：检查同一级大纲标题是否使用了不一致的样式。
  • 未更新域：定位“错误！未找到引用源”等失效交叉引用。

使用步骤

  1. 在“文档检查”分组中勾选需要检查的项目。
  2. 点击 开始检查。
  3. 在右侧检查结果窗格中查看具体原因。
  4. 单击某个问题，Word 会跳转到对应位置。
检查项默认不勾选，避免误触后长时间扫描。所有检查项默认不检查表格内部内容。

软件专用

当当前文档名称中不包含“软件”时，软件专用分组内功能会变灰不可用，避免在普通文档中误用。

功能用途
需求提取打开需求提取窗格，提取需求标识，手动补充需求名称和章节号。
需求追踪打开需求追踪控制台，导入互追文档，建立一对一或一对多映射关系。
软件文档检查识别软件需求规格说明或软件设计说明，并按 GJB 438C 检查明确章节标题是否齐全。

需求提取与追踪

需求提取

需求提取用于从当前文档中提取需求标识，并在右侧窗格维护三列数据：需求标识、需求名称、章节号。

  1. 打开软件文档后点击 需求提取。
  2. 点击窗格中的 提取标识，插件会提取文档中的需求标识。
  3. 提取完成后，插件跳转到第一个需求标识位置。
  4. 在正文中选中需求名称，点击浮动 添加 按钮或窗格中的 添加。
  5. 插件会把选中文字填入当前需求标识对应行，并自动提取所在章节号，然后跳转到下一个需求标识。
  6. 点击 保存，将提取结果保存到当前 Word 文档中，便于下次打开继续使用。
  7. 点击 导出追踪表，可把当前提取结果导出到 Word 光标所在位置；表格左侧为当前文档需求，右侧为空，便于后续补充追踪关系。

批量提取

点击 批量提取 后，使用鼠标选中文字并松开左键即可自动填入当前行，不需要再点“添加”。取消批量提取后恢复手动添加。需求提取窗格打开期间，Word 原生选中文字后的悬浮工具栏会被隐藏，避免遮挡插件添加按钮。

清除

点击 清除 只清除当前行的需求名称和章节号，不清除需求标识。

需求追踪控制台

需求追踪用于把当前文档需求与互追文档需求建立映射关系。当前支持模板包括 SRS->SDS、SDS->SRS、SDS->SDD、SDD->SDS。

  1. 先分别在两个文档中完成需求提取并保存。
  2. 打开当前文档，点击 需求追踪。
  3. 点击 导入互追文档，导入另一份文档的需求提取结果。
  4. 选择追踪模板。
  5. 在精简视图中逐条处理当前需求，或切换到详细视图查看完整列表。
  6. 左侧选择当前需求，右侧可选择一个或多个被追踪需求，形成一对一或一对多关系。
  7. 点击 导出追踪表，确认后把追踪表插入当前 Word 光标位置。

导出结果：左侧需求必须完整输出；如果某条左侧需求没有追踪关系，右侧单元格留空；如果存在一对多关系，右侧按多行显示。

追踪关系会随当前文档保存，避免下次打开后重复建立映射。导出表格字体为黑色，表头会根据文件名推算为软件需求规格说明、软件概要设计说明、软件详细设计说明、软件研制任务书、软件测试说明或系统规格说明。

常见问题与建议

插件没有显示

  1. 确认安装完成后重新打开 Word。
  2. 检查 文件 - 选项 - 加载项 中是否被禁用。
  3. 确认运行环境包含 .NET Framework 4.7.2 和 VSTO Runtime。

软件专用按钮为什么是灰色

当前文档名称需要包含“软件”两个字。插件用这个规则避免在普通文档中误触需求提取、需求追踪和软件文档检查。

标题没有出现在导航窗格

通常是段落的大纲级别为正文。把光标放在该段落，使用“大纲级别”下拉框设置为对应级别。

更新章节号前是否要清理手工编号

如果标题文字前是人工输入的 1、1.1、2.3.1，建议先用“清理 - 清除标题前的手工编号”。如果数字本来就是标题文字的一部分，不要执行该清理。

交叉引用显示错误

优先点击“更新 - 更新题注”，再使用 Word 的更新域功能刷新全文域。如果仍出现“错误！未找到引用源”，勾选“未更新域”并点击“开始检查”逐个定位。

需求提取时添加按钮显示异常

需求提取窗格打开后，选中文字松开鼠标会出现插件自己的“添加”按钮；切换到其它软件时按钮会自动隐藏。批量提取模式下不会显示“添加”按钮，而是自动填入当前行。

批量替换前的建议

  • 先在一个副本文档中验证规则。
  • 替换术语时尽量使用准确的查找文本，避免误替换。
  • 跨多个文件替换前，建议备份原始文件夹。
